`leaders_marketplace.fbl_enabled` (Settings > Marketplace > "Marketplace Warehouse (FBL)"), default True (seeded "True"; only True/true/1 = on). Existing DBs get the seed on -u so FBL stays ON. Off => FBM only.

## MODELS_FIELDS_MIGRATIONS
Non-stored computed Boolean `fbl_enabled` on leaders.marketplace.offer and leaders.buybox.config (view helpers). No migration.

## ROUTES_API
No new routes. `/my/vendor/products/new` (POST), `.../sell-existing`, `.../<id>/edit` re-render the form with "Fulfilled by Leaders (FBL) is not available..." when fulfillment_type=fbl and FBL is off.
REUSABLE HELPER for B2 (bulk import) and B4 (vendor API):
- `env["leaders.marketplace.offer"]._leaders_fbl_allowed()` -> bool
- `env["leaders.marketplace.offer"]._leaders_check_fulfillment_type(ft)` -> raises UserError if ft == "fbl" and FBL off, else returns ft
- `env["res.partner"]._leaders_fbl_enabled()` / `_leaders_fbl_disabled_message()`
The offer constraint also refuses FBL as a last line of defence (ValidationError).
