Conventions

  • Same as the other contracts: JSON, no envelope, camelCase, optional fields are omitted when unset, errors are { code, message, fields? }.
  • No cache. Every endpoint here answers Cache-Control: no-store, the pictures too.
  • Language. Texts the admin writes (address, legal name, page title and content, testimonial name, role, company and quote) and every error message come in the language of Accept-Language. A text without a translation falls back to English.
  • CORS as before: localhost:3000, spark-fu.com, new.spark-fu.com.
  • Pictures (company film poster, testimonial portraits) are absolute URLs on the API host with a unique stamp that changes when the picture changes. Use them as they come.

Equipment listings

POST/equipment-listingsA customer offers a machine for sale or rentno auth; Bearer optional

The form of List your equipment. Every field is checked and every problem is reported in one answer, in the language of Accept-Language. Nothing is saved on a 422. A valid Bearer links the listing to the user; an invalid one counts as a guest, never 401. Each listing gets an SL- reference and a to-do for the sales team in Odoo. locale is kept with the listing; when it is missing or not ar/en, the language of the request is used.

Body

interface EquipmentListingRequest {
  name: string;           // 2 to 80 characters
  phone: string;          // E.164, e.g. "+201001234567"
  intent: "sell" | "rent";
  equipmentType: string;  // free text, 2 to 120 characters
  condition: "new" | "used" | "refurbished";
  quantity: number;       // whole number, 1 or more
  description?: string;   // up to 1000 characters
  locale: "ar" | "en";
}
// 201 { "reference": "SL-1001" }

Rules

FieldRuleMessage (en)
namerequired, 2 to 80 characters after trimmingName is required. / Name must be 2 to 80 characters.
phonerequired, E.164Phone is required. / Enter the phone in international format, e.g. +201001234567.
intentsell or rentChoose sell or rent.
equipmentTyperequired, 2 to 120 charactersRequired. / Equipment must be 2 to 120 characters.
conditionnew, used or refurbishedChoose new, used or refurbished.
quantitywhole number, 1 or moreQuantity must be a whole number, 1 or more.
descriptionoptional, up to 1000 charactersThe description can be at most 1000 characters.

Rate limit: 5 per 10 minutes per IP, as an anti-spam rule. Listed IPs are exempt. An empty string counts as a missing field.

Account extras

POST · DELETE/account/avatarUpload or remove the profile photoBearer

DELETE /account/avatar                           → 200 AccountProfile, avatar: null

POST/auth/googleSign in with a Google ID tokenno auth

Send the ID token from Google Identity Services. The backend checks it with Google: audience, issuer and a verified email. It answers exactly like /auth/login: 200 SessionResponse and the same cookies. The first sign-in creates the account from the Google name and email; later ones sign in to the same account, whatever the case of the email. Until the backend enters the Google client ID it answers 503 google_disabled, as below.

// { "idToken": "…", "remember": true }
// 200 SessionResponse (+ refresh cookie, as /auth/login)
// 401 invalid_google_token   the token is not valid for our client ID
// 403 account_disabled       the account exists but is disabled
// 502 google_unavailable     Google could not be reached
// 503 google_disabled        no client ID configured yet

  "message": "تسجيل الدخول بجوجل غير متاح."

Managed in Odoo

  • Equipment listings: Marketplace › Operations › Equipment Listings. Users in the Equipment Listing Sales group get a to-do for each new one.
  • Site settings and company film: Marketplace › Configuration › Storefront › Site Settings (Arabic and English for the address and legal name).
  • Pages: Marketplace › Configuration › Storefront › Pages. Write the text in both languages, then tick Published.
  • Testimonials: Marketplace › Configuration › Storefront › Testimonials. Published needs Customer gave permission.

Open points

  • Content. The live server has no site settings, pages, film or testimonials entered yet. Until then /pages/:slug answers 404, /company-story {} and /testimonials []. Do not show /site-settings until we confirm the company details are entered.
  • Google sign-in. It answers 503 google_disabled until we enter the client ID. We will send you the same client ID for the browser.
  • Listings in the account. GET /account/orders has no fourth kind, so its answer stays as it is. Tell us if signed-in customers should see their listings.
  • Rate limit. Send us the IPs of the build server, the development server, the production website server and each developer, and we will exempt them.
