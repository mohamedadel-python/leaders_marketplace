# Spark Fu: Odoo 18 modules

All the Odoo modules of the Spark Fu marketplace are in `spark_fu_addons/`. Add that folder to Odoo's `addons_path`.

| Module | What it does |
|---|---|
| `leaders_marketplace` | The multi-vendor marketplace: vendors, products, orders, the storefront REST API |
| `spark_fu_website` | Blog, comments, contact form and landing page backend with a REST API |
